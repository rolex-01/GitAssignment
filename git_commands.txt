
GIT COMMANDS AND EXPLANATIONS

1. git --version
   Checks the installed Git version.

2. git config --global user.name "Your Name"
   Configures the Git username.

3. git config --global user.email "your-email@gmail.com"
   Configures the Git email address.

4. git init -b main
   Initializes a local Git repository with main as the default branch.

5. git status
   Displays the current repository status.

6. git add .
   Adds all non-ignored changes to the staging area.

7. git commit -m "Initial project setup"
   Creates the initial project commit.

8. git log --oneline
   Displays commit history in a compact format.

9. git branch feature
   Creates a branch named feature.

10. git switch feature
    Switches to the feature branch.

11. git branch
    Displays all local branches.

12. git commit -m "Updated homepage content"
    Saves the homepage modification.

13. git commit -m "Added feature branch content"
    Commits changes made in the feature branch.

14. git switch main
    Switches back to the main branch.

15. git merge --no-ff feature -m "Merge feature branch into main"
    Merges the feature branch into main and creates a merge commit.

16. git log --oneline --graph --all
    Displays commit history with branch and merge relationships.

17. git add .gitignore
    Stages the .gitignore file.

18. git commit -m "Added gitignore configuration"
    Commits the .gitignore configuration.

19. git check-ignore -v debug.log
    Shows the rule responsible for ignoring the log file.

20. git check-ignore -v temp\temporary.txt
    Shows the rule responsible for ignoring the temporary folder file.

21. git commit -m "Added temporary content"
    Creates an additional commit for the undo demonstration.

22. git revert HEAD
    Reverses the changes introduced by the latest commit.

23. git log --oneline -5
    Displays the latest five commits.

24. git remote add origin https://github.com/rolex-01/GitAssignment.git
    Connects the local repository to GitHub.

25. git remote -v
    Displays the configured remote repository URLs.

26. git push -u origin main
    Pushes the main branch to GitHub.

27. git push -u origin feature
    Pushes the feature branch to GitHub.
